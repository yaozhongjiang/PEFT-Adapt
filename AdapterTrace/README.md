# AdapterTrace

Black-box **run provenance** for parameter-efficient adapters: an owner tests
whether a suspect service runs (a modified copy of) its adapter, with a
calibrated false-accusation rate against independently trained adapters of
the same recipe. The test correlates the suspect's shadow-referenced
per-example scores with the learning rate each training example received in
the owner's run (schedule weight), and is wrapped in a commit-and-verify
protocol against malicious accusers.

This directory is the artifact of the paper. It is self-contained and
independent of the rest of this repository.

## Layout

| Path | Content |
|---|---|
| `src/adaptertrace/` | data loading, training and scoring helpers (Hugging Face / PEFT) |
| `scripts/` | experiment and analysis scripts (see mapping below) |
| `configs/provenance/` | training configurations of the adapter grids (Llama-3.1-8B / Qwen2.5-7B on Dolly and TOFU, merge partners, other-data adapters) |
| `configs/mnli/` | MNLI low-signal stress-test grid |
| `results/raw/` | per-example log-likelihoods of every grid adapter, interface, evasion, distillation and text-only experiment, replayed trainer orders (`.npz`) |
| `results/reports/` | per-experiment JSON reports used for the paper's tables |
| `case_study/` | self-hosted vLLM multi-LoRA case study: commitments, scores, report, RFC 3161 timestamp tokens |
| `analysis/` | analyses added in revision (mechanism table, ablations, adapter-anchored binding, last-exposure weight) |

## Reproducing the statistics from the released scores (CPU only)

```bash
pip install numpy scipy
python analysis/tab1.py tab1    # Table 1 ablations (Monte-Carlo permutation p-values)
python analysis/tab1.py mech    # mechanism table
python analysis/r3b.py          # combined w_O / last-exposure test on TOFU, calibration on replayed orders
python analysis/r2b.py          # owner vs. best foreign order (adapter-anchored binding)
```

Monte-Carlo null distributions are regenerated by the scripts (the paper used
B = 10^6 draws; the analysis scripts default to 10^5–2×10^5 for speed).

## Re-running training and scoring (GPU)

Training and scoring use Hugging Face `transformers`, `peft`, `datasets`
and `accelerate` (versions recorded in `case_study/commitments.json`).
Each script takes `--config` pointing to a file under `configs/` and writes
under `artifact/`. Base models are loaded by their hub ids
(`meta-llama/Llama-3.1-8B-Instruct`, `Qwen/Qwen2.5-7B-Instruct`; the former is
gated). Adapter weights are not included because of their size
(about 110 MB each, more than 150 adapters); they can be regenerated
from the configurations and seeds.

## Verifying the case-study commitments and timestamps

```bash
cd case_study
python - <<'PY'
import json, hashlib
r = json.load(open("commitments.json"))
for o, v in r.items():
    body = {k: x for k, x in v.items() if k != "digest"}
    d = hashlib.sha256(json.dumps(body, sort_keys=True, separators=(",", ":")).encode()).hexdigest()
    print(o, d == v["digest"])
PY
cd timestamps
for o in 401 402 403 404 405; do
  openssl ts -verify -digest $(cat digest_$o.txt) -in resp_$o.tsr -CAfile cacert.pem -untrusted tsa.crt
done
```

The tokens were issued by the public RFC 3161 authority freetsa.org after the
case study had run; they demonstrate the mechanism and its cost, not
precedence in this experiment.
